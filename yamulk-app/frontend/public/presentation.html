🔍 Problem Context

Why YamuLK?

Sri Lankan travelers face significant friction in domestic trip planning

  • Difficult to estimate total trip cost in advance
  • Unreliable information about local transport options
  • No personalized recommendations based on user budget
  • Limited weather guidance for planning outdoor activities

📋 Criterion 1 — 15 Marks
Well-designed, clear, relevant

Questionnaire & Interview Design

Two complementary methods to cover all 5 target user groups

Method 1 — Online Survey (Google Forms)
Section A — Personal Information
  • Q1Age group (Under 18 / 18–25 / 26–35 / 36–45 / 45+)
  • Q2Occupation (Student / Govt / Private / Self-employed)
  • Q3District of residence
Section B — Travel Behavior
  • Q4How often do you travel within Sri Lanka?
  • Q5Who do you usually travel with?
  • Q6Preferred destination types (beaches, mountains…)
  • Q7Primary transport method used
Section C — Planning Habits
  • Q8How do you currently plan trips?
  • Q9Difficulties faced while planning (multi-select)
  • Q10Average budget for a one-day trip
Section D — Feature Requirements
  • Q11Desired app features (multi-select, 10 options)
  • Q12Importance of budget estimation feature
  • Q13Would you use an AI recommendation app?
  • Q14Preferred ease-of-use level
  • Q15Additional suggestions (open-ended)
Method 2 — Semi-structured Interviews
🎯 Target for Interviews
  • Group D — Corporate trip planners (25–45): deep pain points around group booking
  • Group E — Elderly/pilgrimage travelers (55+): accessibility, low tech literacy
📊 Distribution Channel
  • Google Forms link distributed via WhatsApp & Facebook Groups
  • Targeted at Groups A, B & C (high reach)
  • Interviews conducted in-person for Groups D & E
✅ Design Rationale
  • Questions structured from general → specific
  • Mix of closed (fast analysis) and open-ended (depth)
  • Covers all 5 user groups across 2 methods
  • Pilot-tested for clarity before distribution

Key Insights from Data Collection
  • All groups want a single unified platform — fragmented tools are the #1 pain
  • Budget estimation ranked "Very Important" by 87% of respondents
  • Groups A & C favor bus/train; Groups B & D prefer private vehicles
  • Group E needs large text, simple navigation and accessibility
  • Most users plan via Google Search + Social Media, not dedicated apps
  • 76% would use an app that auto-recommends based on budget & interests

🎯 Criterion 3 — 20 Marks
Clear goals, structured hierarchy

Requirement Analysis

Main goal decomposed into sub-tasks and mapped to features

🎯 Main Goal
Enable Sri Lankan domestic travelers to plan complete, cost-effective trips from a single platform
Task Hierarchy (Sub-tasks)
1
Discover Destinations
Browse, search, filter by province / category / rating
2
Plan Itinerary
Select destination, travel dates, number of people, transport & accommodation
3
Estimate Budget
Break down transport, accommodation, food, activities, emergency costs per person
4
Plan Route
Compare bus / train / car / bike with distance, time & cost breakdown
5
Check Weather
Current conditions, 7-day forecast and best-time-to-visit guidance per destination
6
Save & Manage Trips
Save itineraries, view saved trips, edit / duplicate / export plans
Functional vs Non-Functional
✅ Functional Requirements
  • User registration / login / guest session
  • Destination search with filters
  • Trip planner form with validation
  • Real-time budget recalculation
  • Multi-mode route comparison
  • Weather dashboard per destination
  • Save/load trip itineraries
⚙️ Non-Functional Requirements
  • Page load < 2 s on 4G mobile
  • WCAG 2.1 AA accessibility
  • Responsive: desktop → mobile
  • Secure JWT auth + HTTPS

User Mental Model Principles Applied
🔁 Feedback Loops
Every action produces immediate visible feedback — budget ring updates as you type, weather card changes when destination changes
🗺️ Hub-and-Spoke Navigation
Home dashboard is the hub. All 8 functional screens are reachable in one click; user never lost (<2 clicks to any screen)
🧩 Affordances & Signifiers
Emoji icons, color-coded badges, and clear labels map precisely to user expectations — no ambiguous controls
📱 Progressive Disclosure
Homepage shows overview; detail pages reveal deeper information only when user explicitly navigates there
