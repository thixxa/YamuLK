Application Overview

YamuLK is a full-stack Sri Lanka tourism web application built with React + Vite (frontend) and Node.js + Express + MongoDB (backend). It provides travellers — both local and international — with tools to discover, plan, budget, and navigate trips across Sri Lanka's 9 provinces and 200+ destinations.
